# Credoxa Go SDKs

This repository is the public Go SDK distribution surface for Credoxa services.

The SDK source is generated from controlled API contracts maintained in the private Credoxa Cloud development repository. Generated SDK code in this repository is a distribution artifact and is not developed manually.

## Events

Module:

`github.com/alhiedi/credoxa-go/events`

Current release:

`v1.0.5`

Install:

    go get github.com/alhiedi/credoxa-go/events@v1.0.5

Because Events is an independent Go module under the `events/` subdirectory, its repository tag is:

`events/v1.0.5`

Future Credoxa service SDKs may be published as independent modules and versioned independently.
